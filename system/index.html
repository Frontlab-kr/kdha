KDHA Design System

지금까지 퍼블리싱한 대표·교육원·회원 화면에서 실제로 쓰는 값과 컴포넌트만 모아 다시 정리한 기준입니다. 기존 화면의 마크업과 클래스는 바꾸지 않았고, 이 문서의 예시도 사이트와 같은 클래스로 그려집니다.

개요

  • 토큰 : src/assets/scss/system/_tokens.scss — 색상·글자·간격·반경·그림자·크기의 단일 기준. CSS 변수( --kd-* )로도 꺼낼 수 있습니다.
  • 컴포넌트 : 사이트 공통 클래스( ds-* , form-* , edu-dialog )를 그대로 씁니다. 사용법은 Components .
  • 기존 문서 : 이전 디자인 가이드( /design-system/ )는 삭제했습니다. 이 문서가 유일한 기준입니다.
  • 원칙 : 같은 역할은 같은 컴포넌트로(ds-* 재사용), 페이지 간격은 상위 페이지 클래스에서만, 완료 페이지는 마크업·클래스를 바꾸지 않고 스타일만.

Color

화면에서는 역할 이름(Semantic)을 쓰고, Primitive는 역할 이름의 원본 값으로만 씁니다. 퍼블리싱 CSS에서 실제 사용 빈도가 높은 값 기준입니다.

Layout · Breakpoint

디자인 기준 화면은 PC 1920 · MO 360입니다. 콘텐츠 폭은 1440px이며 .main-body · .page-hero · .layout-container 가 min(1440px, 100% - 40px) 로 잡습니다.

구간 범위 기준
PC 1101px 이상 콘텐츠 1440px
Tablet 768 ~ 1100px PC 구조 유지, 열 수만 줄임(카드 4→3→2열)
MO 767px 이하 본문(.main-body) = 화면 - 24px (360 → 336), 팝업도 좌우 12px
  • 미디어쿼리는 max-width: 767px , 768px ~ 1100px 두 구간을 기본으로 씁니다.
  • 그 외 값(700·900·1080·1399px 등)은 특정 화면에서 공간이 부족할 때만 예외로 쓰고 주석으로 이유를 남깁니다.
  • 카드 목록: 1400px 이상 4열 / 1101~1399px 3열 / 768~1100px 2열 / 767px 이하 1열.
  • MO 가로 스크롤은 목록 자체에만 overflow-x: auto 를 주고, 페이지에는 overflow-x: clip 을 씁니다.

Icon

Google Material Symbols 폰트를 씁니다. 이미지로 저장하지 않습니다. 브랜드 로고·일러스트만 SVG/이미지로 씁니다.

close search attach_file arrow_forward_ios calendar_month 
<span class="material-symbols-rounded" aria-hidden="true">close</span>
  • Figma 표기 아이콘명(R/400/24) = Rounded · Weight 400 · Optical size 24. R 은 Rounded, 표기가 없으면 Outlined입니다.
  • 표기 없는 기본값: Weight 300 · Grade 0 · Fill 0 · Optical size = 표시 크기.
  • 장식 아이콘은 aria-hidden="true" , 의미 있는 아이콘은 role="img" + aria-label , 아이콘만 있는 버튼은 버튼에 aria-label .
  • 사용 중인 전체 아이콘 목록: Icon 목록 (빌드 시 자동 수집)

Focus · Motion

  • 키보드 포커스: outline 2px #ad99ff , outline-offset 2px — 요소 밖으로 4px( focus-ring-space )를 차지합니다. 전역 규칙이므로 지우지 않습니다.
  • 텍스트 입력은 포커스 링 대신 테두리를 primary 로 바꿉니다.
  • 스크롤 영역(팝업 본문 등) 안에서는 focus-ring-room 믹스인으로 4px 여유를 줍니다. 여유를 줄 수 없는 가로 스크롤 탭·카드는 테두리를 안쪽( outline-offset: -2px )에 그립니다.
  • 모션: 기본 160~180ms ease. hover는 색 변경 + 필요 시 2px 떠오름, prefers-reduced-motion: reduce 에서는 이동·자동재생을 끕니다.

기존 토큰 대응

기존 토큰 파일 2개( src/assets/scss/_tokens.scss , modules/styles/foundation/_tokens.scss )는 이름이 같아도 값이 다른 경우가 있습니다. 새 토큰은 src/assets/scss/system/_tokens.scss 하나입니다.

기존 토큰은 화면 유지를 위해 지우지 않습니다. 기존 SCSS를 고칠 때 아래 대응표로 새 이름으로 바꾸고, 바꾼 뒤 화면 차이가 없는지 확인합니다.
