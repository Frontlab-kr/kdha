Components

사이트에서 실제로 쓰는 공통 컴포넌트입니다. 아래 예시는 사이트 style.css 와 common.js 로 그려지므로 실제 화면과 같습니다. 새 화면은 이 마크업을 그대로 복사해 씁니다.

Button

핵심 행동은 Primary, 보조 행동은 Outline입니다. 한 화면의 Primary는 가능한 하나로 제한합니다.

<button class="ds-button ds-button--small ds-button--primary" type="button">버튼 S</button>
<button class="ds-button ds-button--large ds-button--outline" type="button">버튼 L</button>
<button class="ds-button ds-button--medium ds-button--outline" type="button">버튼 M</button>

  영수증 출력
  <span class="material-symbols-rounded" aria-hidden="true">print</span>
</button>
<button class="ds-button ds-button--large ds-button--primary" type="button" disabled>Disabled</button>

  • 클래스 순서: ds-button → 크기 → 스타일 (예: ds-button ds-button--large ds-button--primary ). 크기·스타일을 빠뜨리지 않습니다.

  • 팝업 하단 버튼은 .edu-dialog__actions 안에서 최대 240px, MO 전체 폭으로 자동 조정됩니다.

크기·스타일 순서가 섞여 있음( --small --outline / --outline --small ) — 새 작업은 위 순서로.
쓰지 않는 버튼 클래스: .dialog-button , .edu-button , .edu-account-button , .english-button

Filter chip

목록 위 상태 필터입니다. 높이 43px, 선택 시 보라 테두리·글자(배경은 흰색).

<div class="mypage-filter" role="group" aria-label="결제상태" data-mypage-filter="sample-list">
  <button type="button" aria-pressed="true" data-filter-value="all">전체</button>
  <button type="button" aria-pressed="false" data-filter-value="paid">결제완료</button>
  <button type="button" aria-pressed="false" data-filter-value="refund">환불신청</button>
</div>
  • data-mypage-filter="목록 id" + 버튼 aria-pressed · data-filter-value , 목록 행에 data-filter-item="값" (mypage.js).
  • 선택 상태는 aria-pressed="true" 로만 표시합니다.
정리 필요
같은 역할의 다른 모양: .ds-tabs--pill (채움형, 정회원 안내), .jobs-chips . 디자인 확인 후 하나로.

Tabs

밑줄형(기본), 박스형( --box ), 알약형( --pill ) 세 가지입니다.

기본 · 패널 전환 
<div class="ds-tabs" data-tabs role="tablist" aria-label="본인인증 방식">
  <button class="ds-tabs__item" id="sg-tab-1" type="button" data-tab role="tab" aria-selected="true" aria-controls="sg-panel-1">휴대폰인증</button>
  <button class="ds-tabs__item" id="sg-tab-2" type="button" data-tab role="tab" aria-selected="false" aria-controls="sg-panel-2" tabindex="-1">아이핀인증</button>
</div>
박스형 · 페이지 이동
현장교육 안내 사이버교육 안내 
<nav class="ds-tabs ds-tabs--box" aria-label="교육 유형">
  <a class="ds-tabs__item" href="#tabs">현장교육 안내</a>
  <a class="ds-tabs__item" href="#tabs" aria-current="page">사이버교육 안내</a>
</nav>
알약형 · 필터 
<div class="ds-tabs ds-tabs--pill" role="group" aria-label="회원 구분">
  <button class="ds-tabs__item" type="button" aria-pressed="true">정회원</button>
  <button class="ds-tabs__item" type="button" aria-pressed="false">준회원</button>
</div>
  • 선택 표시: 패널 탭 aria-selected , 필터 aria-pressed , 페이지 이동 a[aria-current="page"] . 모두 같은 .ds-tabs__item .
  • 패널 탭: data-tabs + data-tab + aria-controls , 패널은 role="tabpanel" . 방향키·Home·End 지원(common.js). 탭 밖 버튼으로 바꿀 땐 data-tab-target .
  • 박스형은 PC 균등 분할(높이 66), MO는 가로 스크롤 알약. MO에서도 균등 분할이면 --fill , 항목이 많으면 --compact .
  • 간격 조정은 상위 페이지 클래스에서만( .community-page .ds-tabs ). community-tabs 같은 복제 금지.
정리 필요
탭 JS가 두 가지( data-tab / data-public-tab ) — 새 작업은 data-tab .
이전 탭 클래스 잔여: .edu-tabs , .public-tabs , .community-section-tabs .

Input

입력 필드입니다. 라벨 16 Bold · 라벨 간격 8 · 도움말 간격 6 · 반경 12.

<label class="form-field form-field--large">
  <span>이름</span>
  <input type="text" placeholder="이름 입력" />
</label>
<label class="form-field form-field--large form-field--helper has-error">
  <span>이메일</span>
  <input type="email" value="kdha@" aria-describedby="sg-email-error" />
  <small id="sg-email-error">이메일 형식이 올바르지 않습니다.</small>
</label>
<label class="form-field form-field--large">
  <span>아이디</span>
  <input type="text" value="kdha2026" disabled />
</label>
<label class="form-field">
  <span>문의 내용</span>
  <textarea placeholder="내용을 입력해 주세요."></textarea>
</label>
크기 PC MO
form-field (M) 48px 48px
form-field--large (L) 56px 48px (자동)
  • 상태: 오류 has-error (테두리·도움말 빨강), 도움말 표시 form-field--helper , 비활성 disabled / readonly .
  • 포커스는 전역 링 대신 테두리 보라입니다.
  • 오류 문구는 aria-describedby 로 입력과 연결합니다.
  • MO 높이를 페이지에서 다시 지정하지 않습니다.
정리 필요
.edu-field 는 .form-field 와 같은 별칭 — 새 작업은 form-field .

Select

select[data-custom-select] 를 쓰면 공통 드롭다운( .ds-select )으로 바뀝니다. 원본 select 값과 동기화됩니다. 

<label class="form-field form-field--large">
  <span>교육분류</span>
  <select data-custom-select data-select-size="l">
    <option>전체</option>
    <option>치위생 및 보건</option>
    <option>필수과목</option>
  </select>
</label>
  • 크기: data-select-size="l" (56, MO 48) / 기본 m(48).
  • 첫 option은 placeholder로 처리됩니다. 첫 값이 실제 값이면 option[data-placeholder="false"] .
  • required 면 제출 시 미선택 오류를 표시합니다.
  • 값을 JS로 바꾼 뒤 $(select).trigger('change') , AJAX로 추가한 영역은 KDHAComponents.initCustomSelects(영역) .
정리 필요
원본 select에 class="ds-select" 를 붙인 곳(9곳)이 있음 — 생성되는 래퍼와 이름이 겹치므로 새 작업은 붙이지 않음.
data-custom-select 없이 OS 기본 셀렉트로 남은 곳 6곳.

네이티브 input을 그대로 쓰고 모양만 바꿉니다. 18px 컨트롤 · 24px 누름 영역 · 라벨 14px.

<label class="form-check">
  <input type="checkbox" checked />
  <span>전체 동의</span>
</label>
<label class="form-check">
  <input type="checkbox" />
  <span>선택 안 함</span>
</label>
<label class="form-check">
  <input type="radio" name="sg-radio" checked />
  <span>동의함</span>
</label>
<label class="form-check">
  <input type="radio" name="sg-radio" />

<label class="form-check">

  • 기타 + 직접입력은 .jobs-choices__etc 패턴(체크박스 + 입력 240px).

Input + 버튼

중복확인·주소찾기·전액 사용처럼 입력 옆에 붙는 버튼입니다.

<div class="form-field form-field--large">
  <label for="sg-mileage">마일리지</label>
  <span class="form-input-action">
    <input id="sg-mileage" type="text" value="5,000" />
    <button class="form-action-button" type="button">전액 사용</button>
  </span>
</div>
  • 버튼은 .form-action-button (56px, radius 12, 18 Bold; MO 48px). --medium 은 48px.
  • 입력과 버튼 간격 8px.

조회 박스

게시판 목록 위 검색입니다. 셀렉트 + 입력 + 검색 버튼을 공통 컴포넌트로 조합하고, 박스 배경·배치만 페이지 클래스가 맡습니다. 

<form class="community-search form-field form-field--large" role="search">
  <select data-select-size="l" data-custom-select name="field" aria-label="검색 조건">
    <option value="all">선택</option>
    <option value="title">제목</option>
  </select>
  <input type="search" name="query" aria-label="검색어" placeholder="검색어를 입력해 주세요" />
  <button class="form-action-button" type="submit">검색</button>
</form>
  • 컨테이너 form-field form-field--large + 셀렉트 data-select-size="l" + 버튼 .form-action-button .
  • 박스 아래와 목록 사이 40px.
정리 필요
알약형 .ds-search 는 실제 화면에서 쓰지 않음. 실제 화면은 위 조회 박스와 .ofe-search , .jobs-search 등 화면별 검색이 있음.

Date picker

날짜·연도 선택기입니다(vanillajs-datepicker).

<div class="form-field form-field--large form-datepicker">
  <label for="sg-date">입학년도</label>
  <span class="form-datepicker__control">
    <input id="sg-date" type="text" inputmode="numeric" placeholder="YYYY" data-datepicker data-datepicker-view="year" />

  • AJAX로 추가하면 KDHAComponents.initDatepickers(영역) / initDateRangePickers(영역) .

Pagination

모든 목록은 .ds-pagination 하나만 씁니다.

1 2 3 4 5 arrow_forward_ios 
<nav class="ds-pagination" aria-label="목록 페이지 이동">
  <button type="button" aria-label="이전 페이지" disabled><span class="material-symbols-rounded" aria-hidden="true">arrow_back_ios_new</span></button>
  <a href="#pagination" aria-current="page">1</a>
  <a href="#pagination">2</a>
  <a href="#pagination">3</a>
  <a href="#pagination">4</a>
  <a href="#pagination">5</a>
  <a href="#pagination" aria-label="다음 페이지"><span class="material-symbols-rounded" aria-hidden="true">arrow_forward_ios</span></a>
</nav>
  • 보조 클래스로 스타일을 주지 않습니다. 위 간격만 상위 클래스에서 조정합니다.
  • 화면 안 갱신은 button , 서버 이동은 a . 현재 페이지 aria-current="page" .
  • PC 44px · 간격 8 / MO 40px · 간격 4. MO에서 폭이 좁으면(팝업 등) 원형을 유지한 채 32px까지 자동 축소.
  • 번호는 5개 단위(이전 + 5 + 다음)로 출력합니다.

Guide list

짧은 안내 문구 박스입니다. 회색 배경 · radius 16 · padding 24 · 항목 간격 4 · 14px.

  • 승인 받은 병원만 공고를 등록할 수 있습니다.
  • 자세한 내용은 이용안내 를 확인해 주세요. 
<ul class="ds-guide-list">
  <li class="ds-guide-list__item">
    <span class="ds-guide-list__content"><strong>승인 받은 병원만</strong> 공고를 등록할 수 있습니다.</span>
  </li>
  <li class="ds-guide-list__item">
    <span class="ds-guide-list__content">자세한 내용은 <a class="ds-link ds-link--text" href="#guide-list">이용안내</a>를 확인해 주세요.</span>
  </li>
</ul>
  • 항목은 반드시 __item + __content 로 씁니다(사각 글머리표 포함).
  • 안내 박스를 페이지 전용으로 새로 만들지 않습니다.
  • 링크 뒤 조사는 닫는 태그 바로 뒤에 붙여 씁니다.
정리 필요
158개 중 약 100개가 __item 없이 일반 <li> — 글머리표가 화면별로 따로 그려짐.

Dialog

일반 팝업입니다. 네이티브 <dialog> 를 씁니다.

팝업 제목

 
<button class="ds-button ds-button--medium ds-button--outline" type="button" data-dialog-open="sg-dialog">팝업 열기</button>
<dialog class="edu-dialog" id="sg-dialog" aria-labelledby="sg-dialog-title">
  <button class="edu-dialog__close material-symbols-rounded material-icon--close" type="button" data-dialog-close aria-label="닫기">close</button>
  <h2 id="sg-dialog-title">팝업 제목</h2>
  <div class="edu-dialog__body">
    <label class="form-field form-field--large">
      <span>이름</span>
      <input type="text" placeholder="이름 입력" />
    </label>
  </div>
  <div class="edu-dialog__actions">
    <button class="ds-button ds-button--large ds-button--outline" type="button" data-dialog-close>취소</button>
    <button class="ds-button ds-button--large ds-button--primary" type="button" data-dialog-close>확인</button>
  </div>
</dialog>
PC MO
너비 560px (넓은 팝업 900 · 960) 화면 - 24px
여백 40px 40px 20px
영역 간격 40px 32px
제목 28px Bold 20~24px
그림자 shadow-dialog shadow-card
  • 열기 data-dialog-open="id" , 닫기 data-dialog-close , 다음 팝업으로 교체 data-dialog-switch="id" . 주소에 #id 를 붙이면 열린 상태로 시작.
  • aria-labelledby 로 제목 연결. 닫으면 연 요소로 포커스가 돌아갑니다.
  • dialog 자체는 스크롤하지 않고 .edu-dialog__body 만 스크롤(포커스 여유 포함).
  • 하단 버튼은 .edu-dialog__actions (버튼 최대 240, MO 전체 폭).
정리 필요
공통 팝업인데 클래스가 edu- 로 시작 — 이름은 유지(완료 페이지).
education.js 에 열기·닫기 코드가 한 벌 더 있음(로그인·약관 화면용).

Alert

짧은 알림·확인 팝업입니다. 브라우저 alert() / confirm() 대신 씁니다. 너비 320px.

필수 항목을 모두 입력해 주세요.

 
<button class="ds-button ds-button--medium ds-button--outline" type="button" data-dialog-open="sg-alert">알림 열기</button>
<dialog class="ds-alert" id="sg-alert" role="alertdialog" aria-label="알림" aria-describedby="sg-alert-message">
  <button class="ds-alert__close material-symbols-rounded" type="button" data-dialog-close aria-label="닫기">close</button>
  <p class="ds-alert__message" id="sg-alert-message">필수 항목을 모두 입력해 주세요.</p>
  <div class="edu-dialog__actions">
    <button class="ds-button ds-button--large ds-button--primary" type="button" data-dialog-close>확인</button>
  </div>
</dialog>
  • role="alertdialog" + aria-describedby 로 메시지 연결.
  • 확인 1개: Primary 1개 / 취소·확인: Outline + Primary(균등 분할).
  • 알림 레이어는 모두 ds-alert 로 통일합니다.
정리 필요
확인 버튼이 화면에 따라 Primary/Outline으로 섞여 있음.
