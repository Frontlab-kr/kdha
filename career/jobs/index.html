구인 게시판 이용공지

본 게시판은 대한치과위생사협회에서 운영하는 치과위생사 전용 구인 게시판 이므로 치과위생사 구인 이외의 목적으로는 이용할 수 없습니다.

  1. 01

    본 게시판은 구인회원 간 형평성을 고려하여 1개 계정으로 1개 등록만 가능합니다. 추가 등록 시 자동으로 이전 글이 삭제됩니다.

  2. 02

    2개소 이상의 개설 형태로 운영하는 의료기관(그룹, 연합, 네트워크 등)은 연합형태를 1기관으로 간주하므로 각 개소별 구인글을 취합하여 하나의 게시글로 게시해야 합니다.

  3. 03

    금지어를 비롯한 도배성, 불법성, 음란성, 광고성 글 게재행위가 총 3회 이상 반복되는 경우 강제 탈퇴되며, 재가입 및 해당 기관의 게시판 이용이 금지됩니다.

  4. 04

    게시글은 모집기간 종료 후 자동 삭제되며, 본 협회는 게시글에 대하여 보관의 의무를 가지지 않습니다.

  5. 05

    건전한 게시판 운영을 위하여 금지어가 설정되어 일부 단어를 사용하는 경우 게시되지 않습니다. (금지어 예시 : "최고연봉" "페금" 등)
