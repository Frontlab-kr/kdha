Layout (레이아웃)

레이아웃 그리드는 콘텐츠를 일관된 기준으로 배치하기 위한 구조이다.
화면의 정렬과 간격을 체계적으로 구성하여 시각적 균형을 유지하고, 다양한 디바이스에서도 일관된 사용자 경험을 제공한다.
