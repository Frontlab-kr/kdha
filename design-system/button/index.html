Button

핵심 행동은 Primary, 보조 행동은 Outline을 사용하며 한 화면의 Primary 버튼은 가능한 하나로 제한합니다.

Style & State

Figma의 Style과 State variant를 웹의 hover, active, disabled 상태에 연결했습니다.

Style Default Hover Pressed Disabled Primary Outline

Size

실제 Figma 컴포넌트 높이를 기준으로 L 52px, M 48px, S 40px를 사용합니다.

L · 52px .ds-button--large
M · 48px .ds-button--medium
S · 40px .ds-button--small

Icon

아이콘은 장식 요소로 처리하고 L·M은 20px, S는 16px를 사용합니다.

Markup

화면 이동은 a, 현재 화면에서 실행되는 동작은 button 요소를 사용합니다.

<button class="ds-button ds-button--large ds-button--primary" type="button">
  확인
</button>
