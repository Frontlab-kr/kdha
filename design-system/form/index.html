Figma Input Field의 M 48px, L 56px와 기본·포커스·오류·비활성 상태입니다. L(--large)은 모바일(767px 이하)에서 컴포넌트가 자동으로 M 48px로 줄이므로 페이지별로 모바일 높이를 다시 지정하지 않습니다.

Search

Figma Search · 알약형 L 56px / M 48px(모바일은 M). 셀렉트·입력·버튼을 묶은 조회 박스는 공통 컴포넌트를 조합하고, 박스 배경·배치만 페이지 클래스에서 지정합니다.

Search L · 56px
Search M · 48px
조회 박스 (Select L + Input L + Action Button) 
<!-- 알약형 검색 -->
<form class="ds-search" role="search">
  <input type="search" placeholder="내용을 입력해 주세요" />
  <button type="submit" aria-label="검색"><span class="material-symbols-rounded" aria-hidden="true">search</span></button>
</form>

<!-- 조회 박스: 공통 컴포넌트 조합 + 페이지 배치 클래스 -->
<form class="community-search form-field form-field--large" role="search">
  <select data-custom-select data-select-size="l">...</select>
  <input type="search" />
  <button class="form-action-button" type="submit">검색</button>
</form>
